# Krakus - Website
Responsive multi-page website as a web design and development project | HTML5, CSS3, JavaScript, jQuery


## Project Description
The website provides information about the ensemble, its activities, recruitment process, international performances and contact details. It includes a recruitment form and an interactive photo gallery in the form of a table.

## Features
- Multi-page website with consistent navigation
- Sections describing the ensemble, its repertoire and activities
- Recruitment form with input validation
- Interactive navigation effects and form display animation
- International trips presented in a photo table
- Contact section with an embedded Google Maps view
- Responsive layout adapted to smaller screens

## Technologies
- HTML5
- CSS3
- JavaScript
- jQuery
